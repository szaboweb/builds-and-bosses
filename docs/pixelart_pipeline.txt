Technológiai Core Modulok (Kódrészletek)Modul 1: Az IK Solver (skeleton/ik_solver.py)Biztosítja a fix végtaghosszakat és a pontos pozícionálást, megakadályozva a modellek torzulását.Pythonimport math

def ik_solve_2bone(
    origin: tuple[float, float],
    target: tuple[float, float],
    len1: float,
    len2: float,
    flip: bool = False
) -> tuple[float, float]:
    x0, y0 = origin
    x2, y2 = target
    dx = x2 - x0
    dy = y2 - y0
    dist_sq = dx*dx + dy*dy
    dist = math.sqrt(dist_sq)

    if dist > len1 + len2 or dist < abs(len1 - len2):
        if dist == 0: dist = 0.0001
        scale = (len1 + len2) / dist
        return (x0 + dx * scale * (len1/(len1+len2)), y0 + dy * scale * (len1/(len1+len2)))

    try:
        cos_angle = (len1*len1 + dist_sq - len2*len2) / (2 * len1 * dist)
        cos_angle = max(min(cos_angle, 1.0), -1.0)
        angle_base = math.acos(cos_angle)
    except ZeroDivisionError:
        angle_base = 0

    atan_angle = math.atan2(dy, dx)
    joint_angle = atan_angle - angle_base if not flip else atan_angle + angle_base
    
    joint_x = x0 + len1 * math.cos(joint_angle)
    joint_y = y0 + len1 * math.sin(joint_angle)
    return (joint_x, joint_y)

SIZE = 64
INK = (226, 239, 255, 255)
JOINT = (255, 201, 111, 255)

def draw_skeleton_pose(points: dict[str, tuple[int, int]]) -> Image.Image:
    image = Image.new("RGBA", (SIZE, SIZE), (0, 0, 0, 0))
    draw = ImageDraw.Draw(image)

    segments = (
        ("head", "neck"),
        ("neck", "shoulder"),
        ("shoulder", "hip"),
        ("left_shoulder", "left_elbow"),
        ("left_elbow", "left_hand"),
        ("right_shoulder", "right_elbow"),
        ("right_elbow", "right_hand"),
        ("left_hip", "left_knee"),
        ("left_knee", "left_foot"),
        ("right_hip", "right_knee"),
        ("right_knee", "right_foot"),
    )
    
    for start, end in segments:
        draw.line((points[start], points[end]), fill=INK, width=1)

    head_x, head_y = points["head"]
    draw.ellipse((head_x - 2, head_y - 2, head_x + 2, head_y + 2), outline=JOINT)
    draw.line((points["head"], points["nose"]), fill=INK, width=1)
    
    for name in ("shoulder", "hip", "left_elbow", "right_elbow", "left_knee", "right_knee"):
        x, y = points[name]
        draw.point((x, y), fill=JOINT)
        
    return image

Játékmotoros Integrációs & Átmenet-kezelési SzabályokRoot Anchoring (Gyökérstabilitás): Mivel az IK váz biztosítja a törzs fix sarokpontjait, a Séta, Ugrás és Harc közötti váltáskor a karakter nem ugrál el váratlanul a képernyőn.Felső- és Alsótest Szétválasztás (Layered Animation): Séta közbeni lövésnél vagy varázslásnál a lábak sétaciklusát (walk state) kombinálni kell a felsőtest akciójával (attack/cast state), így megspórolható az összes kombináció külön generálása.Ballisztikus ívek kezelése (jump és fall): Az ugrásnál a váz Y koordinátája a fizikai parabolát követi, de a ComfyUI-ba küldött Canny vázon belül a csontok arányai szigorúan megmaradnak, így az AI nem torzítja el a karaktert a levegőben sem.6. Hibamegelőzési Checklist (Anti-Patterns & Safeguards)[ ] Tilos a dinamikus baseline shift: Soha ne igazítsd a vázat a legalsó lábfej alapján a Y tengelyen (max(foot_y)), mert az a test ugrálását okozza.[ ] Konstans végtaghossz: Kizárólag az IK solver által számolt pozíciókat használd (combszár és alsó lábszár hossza fix).[ ] Nearest-Neighbor skálázás: Tilos a bilinear/bicubic interpoláció alkalmazása a képek méretezésekor, hogy elkerüld a Canny vonalak elszürkülését/elmosódását.[ ] Zárt ciklus ellenőrzés: A loopolható animációknál (idle, walk, run, fall) az utolsó képkocka logikailag és vizuálisan is zökkenőmentesen kösse be az elsőt.[ ] Tükrözési (Mirroring) konzisztencia: Oldalnézetnél (facing == "left") a koordináták horizontális tükrözése mellett a szótár kulcsaiban is kötelező felcserélni a left_ és right_ prefixeket.
